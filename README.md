# 🏠 HomeSync

> Gestión inteligente del hogar compartido — React Native · Node.js · Supabase · Expo

---

## ¿Qué es HomeSync?

HomeSync es una aplicación móvil multiplataforma que permite a varias personas conectarse a un **hogar virtual compartido** donde toda la información relevante del día a día está centralizada y sincronizada en tiempo real.

Diseñada y desarrollada como proyecto personal, probada en **iPhone 16** con Expo.

---

## ✨ Funcionalidades principales

### 🏡 Hogares y miembros
- Crea tu propio hogar o únete a uno existente
- Sistema de **invitaciones nativas de iOS** — al pulsar el enlace se abre el diálogo estándar del sistema para compartir por WhatsApp, iMessage, etc.
- Gestión de perfiles y miembros del hogar

### 🛒 Lista de la compra
- Lista compartida y sincronizada en tiempo real entre todos los miembros
- Añade, tacha y gestiona productos colaborativamente

### 💸 Gestión de gastos
- Registro de gastos del hogar
- Filtros para gastos fijos o variable
- Visión clara de quién ha gastado qué
- Balances y poder saldar cuentas desde la aplicación

### ✅ Tareas del hogar — dos modos de gestión

**Modo Rueda:** las tareas se asignan automáticamente de forma equitativa cada semana, rotando entre los miembros del hogar.

**Modo Competición:** cada tarea tiene un valor en puntos. Al completarla, el miembro acumula esos puntos. Al final del mes se genera un **ranking** con la clasificación de quién ha contribuido más.

### 📅 Calendario compartido
- Añade eventos de cualquier tipo: citas médicas, visitas, planes de ocio...
- Visible para todos los miembros del hogar en tiempo real
- Notificaciones al crear la cita y recordatorios

### 📖 Wiki del hogar
- Espacio de notas compartidas para información relevante del hogar
- Contraseña del WiFi, número del seguro, contactos importantes, cualquier nota que el hogar necesite tener a mano

## 🚀 Cómo ejecutar el proyecto

> El código fuente es privado. Si estás interesado en una demo o revisión del código, puedes contactarme directamente.

Para ejecutar un proyecto Expo similar:

```bash
# Instalar dependencias
npm install

# Iniciar Expo
npx expo start

# Escanear con la app Expo Go en tu móvil
# o pulsar 'i' para el simulador de iOS
```

**Requisitos:**
- Node.js
- Expo CLI
- Cuenta de Supabase con las variables de entorno configuradas
